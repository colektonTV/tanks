# tanks

# Танчики: Битва на двоих

Аркадная игра для двух игроков, вдохновленная классическими "танчиками", с возможностью гибкой настройки игровых параметров.

## Особенности игры

### Классический геймплей с современными возможностями
- Два игрока управляют танками на одном компьютере (WASD vs Стрелки)
- Динамичные бои с возможностью стрельбы и укрытиями
- Система раундов и подсчет очков

### Главное отличие — настраиваемость
В отличие от других игр жанра, вы можете легко настроить основные параметры игры под свой вкус:

- **Выбор карты** — играйте на разных полях боя
- **Количество жизней** — от классического режима "одно попадание — смерть" до затяжных боев с несколькими хитами
- **Количество раундов** — настройте длительность матча

Все настройки хранятся в простом JSON-файле, что позволяет изменять их без вмешательства в код.

## Управление

### Красный танк (WASD)
- **W** — движение вверх
- **S** — движение вниз  
- **A** — движение влево
- **D** — движение вправо
- **Пробел** — стрельба

### Синий танк (Стрелки)
- **↑** — движение вверх
- **↓** — движение вниз
- **←** — движение влево
- **→** — движение вправо
- **Enter** — стрельба

### Общее
- **ESC** — пауза / выход в меню

## Настройка игры

Все параметры игры настраиваются в файле `data/level.json`:

```json
{
    "map": "map_1.tmx",
    "health_multiplier": 3,
    "rounds": 5
}
```

### Параметры настройки

| Параметр | Описание | Примеры |
|----------|----------|---------|
| `map` | Выбор игровой карты | `"map_1.tmx"`, `"map_2.tmx"` |
| `health_multiplier` | Количество жизней танков | `1` (классика), `3` (дольше), `5` (марафон) |
| `rounds` | Количество раундов до победы | `3`, `5`, `10` |

Такая гибкость позволяет:
- Быстро менять сложность для игроков разного уровня
- Проводить турниры с разными правилами
- Экспериментировать с балансом игры

## Установка и запуск

1. Убедитесь, что установлен Python 3.7+
2. Установите зависимости:
```bash
pip install arcade
```
3. Запустите игру:
```bash
python main.py
```

## Системные требования

- Python 3.7 или выше
- Библиотека arcade
- Любая ОС (Windows, macOS, Linux)

## Для разработчиков

Игра написана с использованием библиотеки arcade и следует принципам:
- Чистый код (PEP 8)
- Модульная архитектура
- Легкое расширение функциональности

Вы можете легко добавлять новые карты, изменять механику или создавать свои режимы игры благодаря простой и понятной структуре кода.
